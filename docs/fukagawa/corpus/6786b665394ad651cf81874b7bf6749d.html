母子・父子・寡婦福祉資金の貸付制度 | 北海道深川市 本文へ メニューへ 北海道では、母子家庭・父子家庭の経済的自立の助成と生活意欲の助長・増進を図るため資金の貸付を行なっています。 貸付金制度 次の12種類の貸付金制度があります。（市では、相談、申請窓口を行なっています。） 事業開始資金： 事業を開始するために必要な設備費、資材等の購入資金 事業継続資金： 現在継続中の事業を継続していくための運転資金 修学資金： 子どもが高校・大学等に就学するために必要な資金 技能習得資金： 自ら事業を開始または、就職するために必要な技能や資格を習得するために必要な資金 修業資金： 子どもが事業開始又は就職するために知識技能を習得するために必要な資金 就職支度資金： 就職に必要な被服、履物等を購入する資金 医療介護資金： 医療を受けるために必要な資金 介護保険法に規定する保険給付にかかるサービスを受けるために必要な資金 生活資金： 技能習得及び医療介護資金を借り受けている期間の生活を維持するために必要な資金 住宅資金： 住宅の補修・増改築や住宅取得に必要な資金 転宅資金： 住居移転に際し、住宅の賃借に必要な資金 就学支度資金： 子どもの入学もしくは修業施設への入所に必要な資金 結婚資金： 子どもの婚姻に際し必要な資金 注意 貸付にあたっては、詳細な基準及び各資金に応じて添付していただく書類があります。 また、それぞれ貸付限度額や償還期間、貸付利率等が定められていますので、事前に担当窓口にご相談ください。 トップに戻る 就学支度資金・修学資金の貸付申請受付中 就学支度資金・修学資金の貸付申請受付中 北海道では、母子家庭・父子家庭の子どもたちが、高校や大学などの入学に際して必要な入学金や諸経費、制服などの一時的な支出が困難な場合に利用できる「就学支度資金」と入学後毎月の学費などの支出が困難な場合に利用できる「修学資金」の貸付の申請を受付しています。 利用希望のかたは、必ず下記担当窓口で事前相談をお願いします。 就学支度資金 申込期限： 毎年3月31日まで （31日が土・日にかかる場合はその前日まで） 修学資金 申込期限： 定めなし（随時受付可 ） トップに戻る 問合わせ先・担当窓口 市民福祉部 健康・子ども課 子育て支援係 電話：0164-26-2237 ファクシミリ：0164-22-8134 お問い合わせフォーム トップに戻る サイド・メニュー ようこそ市長室へ 深川市のあらまし お役立ち情報 深川市の条例や規則 （別サイト） （新規ウィンドウで開きます） パブリックコメント 当番医 職員採用情報 市議会会議録検索 （別サイト） （新規ウィンドウで開きます） 市立図書館蔵書検索 （別サイト） （新規ウィンドウで開きます） 各種相談 助成・手当 電子申請 （外部サイト） （新規ウィンドウで開きます） 市内学校（小・中学校、高校、大学など） 関連サイト 公式SNS Facebookページ 深川市役所 （新規ウィンドウで開きます） 本文へ戻る メニューへ戻る ページのトップへ戻る
