保育料について | 北海道深川市 本文へ メニューへ 保育料 保育料は、利用対象のお子さんの父母及び同居の祖父母（家計の主宰者である場合に限ります。）の市町村民税額の合計額によって決定します。 深川市独自の保育料軽減策 国の保育料徴収基準額表から0歳から2歳の課税世帯で50%軽減した額としています。 平成23年度から同時に入所する2人目の保育料を無料化しています。 平成23年度から同時に3人以上入所した世帯の2人目以降の保育料は卒園まで無料です。 令和元年10月1日より、保育園・認定こども園等を利用する3歳から5歳の子ども及び0歳から2歳の非課税世帯の子どもの保育料が無償化されました。 令和7年度深川市保育所保育料徴収基準額表 （PDF:440KB） 北海道多子世帯保育料負担軽減策 平成29年4月から北海道が多子世帯保育料負担軽減支援事業を開始するのに伴い、この事業の活用によって、本市では新たに次の世帯の児童の保育料を無料とし、少子化対策の強化を図るとともに子育て世帯を応援します。 年収約640万円未満（5階層まで）の世帯で3歳未満の第2子以降の児童（最年長の子どもの年齢制限はありません） トップに戻る 保育料の減免及び納付期日の延期 災害、その他特別の理由があると市長が認める場合、保育料の減免又は納期の延期の適用を受けることができます。また平成27年度から非婚のひとり親家庭に対し、寡婦（夫）控除をみなし適用することといたしました。各適用を受けるためには、申請が必要となりますので、担当窓口にご相談ください。 トップに戻る 保育料の納付 納付書払を希望される保護者に郵送します。 口座振替による納入 深川市指定の銀行・信用金庫・農協・ゆうちょ銀行での口座振替が利用できます。原則、毎月末日（土曜・休日の場合は翌営業日）に、ご指定の口座から引き落としさせていただきます。引き落としが出来なかった場合は、翌月に再振替をします。 口座振替の手続きは、口座振替依頼書を市役所に提出してください。 納め忘れがなく安心便利な口座振替をご利用ください。 現金での納入 毎月末日（土曜・休日の場合は翌営業日）までに、お近くの金融機関・市役所・市役所支所で納入してください。 納付場所 北洋銀行（本店及び各支店） 北空知信用（本店及び各支店） きたそらち農業協同組合（本所及び各支所） 全国のゆうちょ銀行 市役所・各支所 トップに戻る その他・備考 入所を希望する方は、認可保育所の入所をご覧ください。 トップに戻る 問合わせ先・担当窓口 市民福祉部 健康・子ども課 子育て支援係 電話：0164-26-2237 ファクシミリ：0164-22-8134 お問い合わせフォーム トップに戻る サイド・メニュー ようこそ市長室へ 深川市のあらまし お役立ち情報 深川市の条例や規則 （別サイト） （新規ウィンドウで開きます） パブリックコメント 当番医 職員採用情報 市議会会議録検索 （別サイト） （新規ウィンドウで開きます） 市立図書館蔵書検索 （別サイト） （新規ウィンドウで開きます） 各種相談 助成・手当 電子申請 （外部サイト） （新規ウィンドウで開きます） 市内学校（小・中学校、高校、大学など） 関連サイト 公式SNS Facebookページ 深川市役所 （新規ウィンドウで開きます） 本文へ戻る メニューへ戻る ページのトップへ戻る
